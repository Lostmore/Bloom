После переподключения

Заново загрузи комнаты и историю через HTTP. Убирай дубли по ID сообщений. Событие new_message с payload.id = 0 означает обновление комнат, а не новое сообщение истории.

Контракт сервиса

В разделе «Сообщения» находятся направления и примеры. Адреса, авторизация и подробные схемы — в полной спецификации.

Особенности текущего протокола

Все события используют type/payload, ошибки — type/error. События действий не содержат серверных времён: точные отметки бери из HTTP-истории. Нет request_id и восстановления пропущенных событий. Presence отражает соединение, без last_seen и настроек скрытой активности. Полные ограничения указаны в спецификации.

Полная спецификация

Официальный просмотрщик AsyncAPI: RECEIVE означает, что сервис получает данные от приложения; SEND — отправляет приложению.
