КАК ЧИТАТЬ КАРТУ

Архитектура, которой можно доверять.

Карта собрана из Compose, маршрутов Gateway, Spring-контроллеров и OpenAPI Go-сервисов. Она не проверяет, запущены ли контейнеры.

Автоматически: сервисы, порты, маршруты, API и список исходных файлов. Вручную сверены: связи между сервисами, особенности авторизации и сценарии. После изменения логики они могут потребовать пересмотра.

Нажмите на карточку или линию. В разделе «Исходники» видны файлы, на которых основано описание. Янтарный цвет означает незавершённую интеграцию или заготовку.

Для обновления запустите python infrastructure/architecture/serve.py. Сервер следит за исходниками; открытая страница получает обновления автоматически. При открытии HTML двойным кликом показывается сохранённый снимок.
